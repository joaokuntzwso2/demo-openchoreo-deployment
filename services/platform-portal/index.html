OpenChoreo platform evidence

From golden path to governed runtime

The business applications are deliberately built on platform primitives that can be inspected live. OpenChoreo owns the developer-platform abstraction and delivery model; Kubernetes and SUSE Rancher remain visible underneath.

Developer self-service

Backstage developer experience

Projects, Systems, Components and live entity views connect software ownership to builds, deployments, logs, events, metrics, alerts, traces, incidents, RCA and cost analysis.

OPENCHOREO
Golden paths

ProjectType + platform abstractions

The regulated platform template generates per-environment Cell infrastructure, quotas, limits, security labels, baseline isolation and operational RBAC from reusable platform policy.

SELF-SERVICE
Software delivery

Immutable releases + promotion

ReleaseBindings and ProjectReleaseBindings separate immutable software from environment-specific configuration and drive the development → staging → production lifecycle.

GOVERNED
Platform services

Resources + ResourceTypes

The payment domain consumes a managed Valkey idempotency cache as a platform resource, demonstrating how application teams request capabilities instead of hand-building infrastructure.

MANAGED
Cross-cutting standards

Traits + observability

Reusable operational behavior carries alerting, AI-assisted RCA signals and FinOps evidence into workloads without pushing those concerns into business-service code.

OBSERVABLE
Regulated-platform controls

Authorization + policy workflows

Declarative scoped authorization protects production operations while the workflow plane models security-scan and change-ticket gates for controlled promotion.

CONTROLLED
Agentic operations

SRE, FinOps + Portal Assistant

Optional OpenChoreo agents turn telemetry and platform context into root-cause, cost and developer assistance while keeping the Portal Assistant read-only by contract.

OPTIONAL
Runtime evidence

Kubernetes Operations

Inspect the real Kubernetes workloads and execute intentionally constrained demo operations to prove that the platform abstractions resolve to standard Kubernetes resources.

KUBERNETES
SUSE partnership story

Rancher sees the same estate

Open the imported cluster in SUSE Rancher to inspect namespaces, workloads and cluster agents from the infrastructure/operator perspective. Rancher complements OpenChoreo; it does not replace its control plane.
